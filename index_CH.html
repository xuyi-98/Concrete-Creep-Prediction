关键龄期预测值

同一行所有量均取同一实际龄期 t = t′ + 持荷时间（εsh 为该龄期值，干燥时长 = t − t₀），故 总应变 = σ·J + |εsh| 在行内严格可复核。φ 为各模型自身定义；J 含瞬时弹性；C = J − 1/E(t′)；收缩为负（B4/B4s/MC2010 含自生收缩）。
模型来源：B4 / B4s — RILEM TC-242-MDC（Bažant 主持）, Materials and Structures 48:753–770 (2015)，B4 按配合比、区分干燥与自生收缩，B4s 为仅按强度的简化变体（常数按原文 Table 1–3、7–9，原文算例中 s₄=6.9×10⁻³ 与 Table 9 之 4.0×10⁻³ 不一致处按表取值）；fib Model Code 2010；CEB-FIP Model Code 1990（中国 JTG 3362、GB/T 50010 徐变收缩条文同源）；ACI 209R-92；B3 — Bažant & Baweja, RILEM TC-107 (1995)。
数据来源：Northwestern University Creep and Shrinkage Database, MySQL 版 2021-05-03（Šmilauer, Dohnalová, Šulc, Wan-Wendner, Bažant），软件内置其筛选降采样子集（范围与口径见下"内置数据范围"）。水泥类型（MC90 SL/N/R/RS）经 creep_test/shrinkage_test → specimen → mix (M_cem_ModelCode_type) 提取，徐变已知 966/1022 组、收缩已知 1040/2452 组，作为匹配时的可选硬过滤（未知类型保留）。
内置数据范围：NU 数据库正式版（2021-05-03）经筛选降采样的子集——入选条件为温度 15–30 ℃ 或未记录、RH/V-S/龄期/强度/水灰比齐全、≥5 个有效数据点且剔除原库标记的可疑点；徐变 1022 / 1438 组（10 106 / 29 184 点），收缩 2452 / 3558 组（27 356 / 69 463 点），每组按对数时间降采样至 ≤12 点（保持曲线形态）。其中温度 25–30 ℃ 的 35 组（徐变 4、收缩 31）默认不参与匹配，勾选"含 25–30 ℃ 试验"后纳入并在表中以橙色温度标示。匹配与散点对比均在该子集内进行，不构成对全库的完整统计校验。
使用须知：① 预测值为平均趋势，实测离散系数通常达 ±30%，重要结构应辅以同条件试验；② 应力水平 σ/fc(t′) ≤ 0.4 时线性徐变假定成立；③ 本工具供方案比选与施工期变形估算参考，最终设计以现行规范计算为准。
