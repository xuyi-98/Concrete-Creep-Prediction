# Concrete Creep Prediction

A visual concrete creep prediction and design software based on the NU database (MySQL, May 3, 2021), designed to support creep knowledge learning and provide reference assistance for construction design.

一款基于 NU 数据库（MySQL，2021 年 5 月 3 日）的可视化混凝土徐变预测与设计软件，用于支持徐变知识学习，并为施工设计提供参考辅助。

## Software

- [English version](index.html)
- [中文版](index_CH.html)

Both versions are self-contained HTML applications. Download the corresponding file and open it in a modern web browser.

两个版本均为独立 HTML 应用。下载对应文件后，使用现代浏览器打开即可运行。

## Data Source

Northwestern University Creep and Shrinkage Database, MySQL edition, May 3, 2021.

The software embeds a filtered and downsampled subset of the database for local prediction, comparison, and visualization.

## Notice

The results are intended for learning, preliminary comparison, and construction-stage design reference. Final engineering design should follow applicable standards and project-specific verification requirements.
